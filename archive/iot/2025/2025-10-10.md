# IoT设备安全漏洞资讯（2025-10-10）

## Help Net Security

### [Attackers compromised ALL SonicWall firewall configuration backup files](https://www.helpnetsecurity.com/2025/10/09/sonicwall-firewall-backup-compromised/)

【文章URL链接】：https://www.helpnetsecurity.com/2025/10/09/sonicwall-firewall-backup-compromised/
【文章标题】：Attackers compromised ALL SonicWall firewall configuration backup files
【文章摘要】：攻击者通过暴力破解攻击了SonicWall的防火墙云备份服务，获取了所有使用该服务的客户配置备份文件。受影响的备份文件包含系统设置、网络配置、防火墙规则等敏感信息，尽管凭证和秘密信息被加密，但攻击者可能利用这些信息进行进一步攻击。SonicWall建议客户重置受影响设备的凭证并进行安全审查。

### [联发科修复Wi-Fi和GNSS芯片组多个高危漏洞](https://www.freebuf.com/articles/network/452015.html)

【文章URL链接】：https://www.freebuf.com/articles/network/452015.html
【文章标题】：联发科修复Wi-Fi和GNSS芯片组多个高危漏洞
【文章摘要】：联发科修复了其Wi-Fi和GNSS芯片组中的多个高危漏洞，包括缓冲区溢出、堆溢出和栈溢出等，这些漏洞可能被利用导致设备崩溃、执行任意代码或破坏内存完整性。此外，还修复了GNSS和图像传感器模块中的中危漏洞。

### [TP-Link路由器漏洞允许通过局域网实现Root权限远程代码执行，PoC已公开](https://www.freebuf.com/articles/network/452038.html)

【文章URL链接】：https://www.freebuf.com/articles/network/452038.html
【文章标题】：TP-Link路由器漏洞允许通过局域网实现Root权限远程代码执行，PoC已公开
【文章摘要】：安全研究员Rocco Calvi披露了TP-Link AX1800 WiFi 6路由器（Archer AX21/AX20型号）存在高危漏洞，允许局域网内攻击者以root权限远程执行代码，影响范围包括启用媒体共享功能的路由器。
