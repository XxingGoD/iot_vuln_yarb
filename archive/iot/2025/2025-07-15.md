【文章标题】：Exploits for unauthenticated FortiWeb RCE are public, so patch quickly! (CVE-2025-25257)
【文章摘要】：FortiWeb, a web application firewall by Fortinet, has a critical SQL command injection vulnerability (CVE-2025-25257) that allows unauthenticated attackers to achieve remote code execution with root privileges.
